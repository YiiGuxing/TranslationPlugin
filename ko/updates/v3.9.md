# Version 3.9 (2026-08-23) :id=version-3-9

---

Translation v3.9에 오신 것을 환영합니다. 이번 버전에는 많은 업데이트가 포함되어 있습니다. 주요 하이라이트는 다음과 같습니다:

- [**문서 번역 원문 유지**](#keep-original-documentation) - _Google 번역과 Microsoft 번역에 문서 번역 시 원문 유지 지원 추가_
- [**OpenAI 고급 구성**](#openai-advanced-configuration) - _OpenAI 번역 엔진에 고급 구성 지원 추가 (실험적)_
- [**엔진 구성 빠른 진입**](#engine-config-quick-entry) - _번역 엔진 목록 팝업에 현재 엔진 구성 빠른 진입 추가_

> 이 릴리스 노트를 온라인으로 읽으시려면 [여기](#/ko/updates ':ignore :target=_blank')를 방문하세요.

## 문서 번역 :id=doc-translation

### 원문 유지 :id=keep-original-documentation

이제 Google 번역과 Microsoft 번역에서 문서 번역 시 원문을 유지할 수 있습니다. 활성화하면 번역 문서 옆에 원문이 함께 표시되어 쉽게 비교할 수 있습니다.

![원문 유지](/updates/img/v3_9/keep-original-documentation.png ':size=660×480 :class=round')

?> 해당 엔진 구성(Google 번역 구성 / Microsoft 번역 구성)에서 **"원문 유지"** 옵션을 활성화할 수 있습니다.

## 번역 엔진 :id=translation-engine

### OpenAI 고급 구성 :id=openai-advanced-configuration

OpenAI 번역 엔진에 고급 구성 지원(실험적)이 추가되었습니다. 요청 구성 파일을 통해 OpenAI 호환 chat completion 요청을 사용자 정의할 수 있습니다. 포함 내용:

- 기본 요청 구성과 특정 모델에 대한 독립 구성을 설정할 수 있으며, 각 모델 구성은 기본 구성과 깊게 병합되어 동일한 이름의 항목을 덮어씁니다.
- 언어 매핑(`languageMapping`), 프롬프트 템플릿(`prompt`), 요청 헤더(`headers`), 요청 본문(`body`)을 사용자 정의할 수 있습니다.
- 요청 헤더와 요청 본문의 문자열 값에 `${TEXT}`, `${SOURCE_LANGUAGE}`, `${TARGET_LANGUAGE}` 플레이스홀더를 사용할 수 있습니다.

자세한 설명은 [사용자 정의 요청 구성](/ko/tutorial/configuring_3party_ai_in_openai_translator.md#custom-request-config)을 참조하세요.

OpenAI 구성 대화상자에서 "요청 설정 편집..."을 클릭하면 구성 파일 편집기가 열립니다.

![사용자 정의 요청 구성](/updates/img/v3_9/custom-request-config.png ':size=584×621 :class=round')

!> 팁: 이 기능은 현재 실험적 기능이며 향후 버전에서 언제든지 폐기되거나 변경될 수 있고, 번역에만 적용됩니다(TTS 및 Azure 공급자에는 적용되지 않음).

### 엔진 구성 빠른 진입 :id=engine-config-quick-entry

번역 엔진 목록 팝업 하단에 "현재 번역 엔진 구성" 메뉴 항목이 추가되었습니다. 클릭하면 현재 번역 엔진의 구성 대화상자를 바로 열 수 있어, 플러그인 설정에서 단계별로 찾을 필요가 없습니다.

![엔진 구성 빠른 진입](/updates/img/v3_9/engine_configuration_quick_entry.png ':size=238×338 :class=round')
