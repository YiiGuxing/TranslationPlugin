Welcome to Translation v3.9! We hope you'll enjoy the many updates in this release. Some of the highlights include:

- [**Keep Original Documentation**](#keep-original-documentation) - _Google Translate and Microsoft Translate now support keeping the original text during documentation translation._
- [**OpenAI Advanced Configuration**](#openai-advanced-configuration) - _New advanced configuration support for the OpenAI translation engine (experimental)._

## Documentation Translation :id=doc-translation

### Keep Original Documentation :id=keep-original-documentation

Google Translate and Microsoft Translate now support keeping the original text during documentation translation. When enabled, the original text is displayed alongside the translation for easy comparison.

![Keep Original Documentation](/updates/img/v3_9/keep-original-documentation.png ':size=660×480 :class=round')

?> You can enable the **"Keep Original Document"** option in the corresponding engine configuration (Google Translate configuration / Microsoft Translate configuration).

## Translation Engine :id=translation-engine

### OpenAI Advanced Configuration :id=openai-advanced-configuration

The OpenAI translation engine now supports advanced configuration (experimental). You can customize OpenAI-compatible chat completion requests via a request configuration file, including:

- Configure a default request configuration as well as separate configurations for specific models. Each model configuration is deep-merged with the default configuration, overriding items with the same name.
- Customize language mappings (`languageMapping`), prompt templates (`prompt`), request headers (`headers`), and request bodies (`body`).
- Use `${TEXT}`, `${SOURCE_LANGUAGE}`, and `${TARGET_LANGUAGE}` placeholders in string values of request headers and request bodies.

For more details, see: [Custom Request Configuration](/en/tutorial/configuring_3party_ai_in_openai_translator.md#custom-request-config)

Click **Edit Request Config...** in the OpenAI configuration dialog to open the configuration file editor.

![Custom Request Configuration](/updates/img/v3_9/custom-request-config.png ':size=584×621 :class=round')

!> Tip: This feature is currently experimental and may be abandoned or changed at any time in future versions, and it only applies to translation (not to TTS or the Azure provider).

### Quick Access to Engine Configuration :id=engine-config-quick-entry

A "Configure Current Translator" menu item has been added to the bottom of the translation engine list popup. Click it to directly open the configuration dialog of the current translation engine, without having to navigate through the plugin settings.

![Quick Access to Engine Configuration](/updates/img/v3_9/engine_configuration_quick_entry.png ':size=238×338 :class=round')
