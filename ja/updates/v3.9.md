## ドキュメント翻訳 :id=doc-translation

### 原文を保持 :id=keep-original-documentation

Google 翻訳と Microsoft 翻訳で、ドキュメント翻訳時に原文を保持できるようになりました。有効にすると、ドキュメント翻訳時に翻訳文の横に原文が同時に表示され、見比べやすくなります。

![原文を保持](/updates/img/v3_9/keep-original-documentation.png ':size=660×480 :class=round')

?> 対応するエンジン設定（Google 翻訳設定 / Microsoft 翻訳設定）で **「原文書を保持する」** オプションを有効にできます。

## 翻訳エンジン :id=translation-engine

### OpenAI 詳細設定 :id=openai-advanced-configuration

OpenAI 翻訳エンジンに詳細設定（実験的）が追加されました。リクエスト設定ファイルを使用して、OpenAI 互換の chat completion リクエストをカスタマイズできます。主な機能は次のとおりです：

- デフォルトのリクエスト設定と特定のモデルごとの独立した設定を構成できます。各モデル設定はデフォルト設定と深くマージされ、同名の項目は上書きされます。
- 言語マッピング（`languageMapping`）、プロンプトテンプレート（`prompt`）、リクエストヘッダー（`headers`）、リクエストボディ（`body`）をカスタマイズできます。
- リクエストヘッダーとリクエストボディの文字列値で `${TEXT}`、`${SOURCE_LANGUAGE}`、`${TARGET_LANGUAGE}` のプレースホルダーを使用できます。

詳細は [カスタムリクエスト設定](/ja/tutorial/configuring_3party_ai_in_openai_translator.md#custom-request-config) をご参照ください。

OpenAI 設定ダイアログで「リクエスト設定を編集...」をクリックすると、設定ファイルエディターが開きます。

![カスタムリクエスト設定](/updates/img/v3_9/custom-request-config.png ':size=584×621 :class=round')

!> ヒント：この機能は現在実験的な機能であり、将来のバージョンでいつでも廃止または変更される可能性があります。また、翻訳（TTS と Azure プロバイダーは除く）にのみ適用されます。

### エンジン設定へのクイックアクセス :id=engine-config-quick-entry

翻訳エンジンリストポップアップの下部に「現在の翻訳エンジンを設定」メニュー項目が追加されました。クリックすると、現在の翻訳エンジンの設定ダイアログを直接開くことができ、プラグイン設定を階層でたどって探す必要はありません。

![エンジン設定へのクイックアクセス](/updates/img/v3_9/engine_configuration_quick_entry.png ':size=238×338 :class=round')
